# Brand assets

`mark.svg` is the calling h in its plum square: the favicon, the app icon and the Slack bot avatar. The Slack avatar needs a 512 × 512 PNG rendered from it. The geometry is also in `src/index.ts` as `mark`, so components draw it inline in the current theme.

The mark is a hand-drawn draft and still needs a proper drawing pass. See DECISIONS.md.
