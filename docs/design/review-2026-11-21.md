## 3. Component APIs: one library, not two

The ported primitives already follow most conventions; Holler's own components drift. Adopt these and write them into AGENTS.md:

- **Shape.** `interface Props extends ComponentProps<…>`, spread the rest, `data-slot`, one `export {}`. Optional props written `?: T | undefined`.
- **Rendering as another element.** `render`, everywhere. Button gets it, and `buttonClasses()` on links goes away.
- **Style axes.** `variant` is the visual treatment; `tone` is the meaning (neutral, live, warning, danger); `size` takes tokens; `status` stays for domain status.
- **Names.** `aria-label` for the accessible name, `label` only for visible text; `description` for secondary text; `pending` for in-flight; icons as `ReactNode`.

| # | Where | Now | Proposed |
| --- | --- | --- | --- |
| 1 | `ui/button.tsx:9,16` | `variant="icon"`, `icon` prop | `size: "sm" \| "md" \| "icon-sm" \| "icon"`; icon as a child; `render` |
| 2 | Base UI parts (checkbox, switch, radio-group, popover, tooltip, toast, drawer) | `className` may be a state function, which `cn` silently drops | Narrow to `className?: string \| undefined` |
| 3 | chip, avatar, progress, segmented, skeleton, notice, mode-glyph; several Select, Combobox and Menu parts | Drop `ref`, `id`, `data-*`, `aria-*` | Extend `ComponentProps`, spread the rest |
| 4 | `ui/segmented.tsx` | `items` array, controlled only | `<Segmented><SegmentedItem value count>…` with `value` or `defaultValue` |
| 5 | `ui/popover.tsx` | No `PopoverTrigger` | Export one |

## 4. Leftovers from the Lymi port

1. **Unused dialog modes.** The dialog's place mode (`kind`, `placement`, `scroll`, `DialogBody`, `PlaceShape`, `usePlaceShape`, `endEdge`), built for Lymi's streak page, has no caller. Delete it.
2. **Unused drawer features.** The drawer's snap points and stack are unused, and `DrawerOverlay`, `DrawerPortal` and `DrawerSwipeHandle` are exported but used only inside the file. Delete them, and un-export the rest.
3. **Dead helpers.** `useMouse`, `useWide`, `appleKeyboard`, `modShortcut` and `leavesGroup` have no callers. Delete them, and un-export the file-local ones.
4. **Comments that use Lymi's nouns.** Comments mention card, flame, amber, review card and `IconButton`. Rewrite them in Holler's terms or delete them.
5. **Citations that point nowhere.** Comments cite "ADR 0017" in 7 files, docs that don't exist (`docs/design/system/*.md`) and "its tests" that don't exist. Point them at DESIGN.md or the design site, or delete them.
6. **Notes about where code came from.** "Ported from Lymi", "Holler's addition" and "shadcn's X" openers. Delete them and keep the behaviour clauses.
7. **Radix-era CSS.** The `data-state` branches and the unused `data-closed`, `data-unchecked`, `data-selected` and `data-active` variants never match, because Base UI doesn't set them. The `edge-inset` and `well` utilities are unused, and `well` clashes with `bg-well`. Delete them all.
8. **Misnamed utility.** `glass` means plate plus float shadow, with no blur. Rename it to `floating`.
9. **Dead variable with a raw hex.** `[--lift:0_0_#0000]` in `input.tsx`. Delete it.
10. **Focus ring that generates nothing.** `outline-ring` has no `--color-ring` behind it. Use the focus ring from `styles.css`.
11. **Skip rules for files Holler doesn't have.** `check-styling` skips `browser.test` and `/locales/`. Delete both.
12. **Duplicate keyboard handling.** The drawer list's keyboard model is written twice, wrapping in one and stopping at the ends in the other. Write one helper in `overlay-list.tsx`.
13. **`Shape` declared three times.** Export it once from `device.ts`.
14. **Hand-rolled ref merging.** The textarea merges refs by hand. Use `useMergedRefs`.
15. **Two import styles.** Imports mix `../../lib/` and `@/lib/`. Use `@/lib/`.
16. **Z-index scale with duplicates and bypasses.**
    - Three aliases share each level, and `--z-dropdown` is unused. Keep one name per level.
    - Some layers ignore the scale: dialog and drawer use `z-10`, toast uses `z-[calc(…)]`, and popover borrows the tooltip level. Route them through the scale.
    - Check that Select inside a Dialog opens above it.
17. **A token value retyped.** Toasts write out `--ease-out` by hand. Use the token.
18. **Will break `pnpm verify` on commit.** `fluid-highlight.tsx:17` uses `left-0`. Add an allow comment explaining the measurement is from the physical left.
19. **Duplicated export parsing.** `check-design` and `check-design-coverage` parse exports separately. Share one tested module.
20. **Unused exports and a false comment.** `chartRamp` and `statuses` are unused. The comment on `INSTANT` says every preset becomes it, which isn't true. Delete the exports and fix the comment.
21. **Dated notes and empty wrappers.** Delete the dated "Token review" notes in `tokens.css`, the empty `({ ...props })` destructures, and the one-line `ToastProvider` wrapper.

## 5. Documentation site

Five changes with the most leverage:

1. **Use this, not that.** Each entry gets a `use` and an `instead` field, and the set of variants is closed ("4 variants, nothing else"). Add decision trees where options compete:
   - which Button variant
   - RadioGroup, Select or Combobox
   - Notice, Toast or Dialog
   - EmptyState, EmptySection or NoResults
2. **Code and props on every example.** Each variant has copyable source and a props table generated from the union types.
3. **Do and don't, plus accessibility, on component pages.** At the moment these appear only on foundation pages. Add `dont` (with incorrect code) and `a11y` fields, and make the coverage check require them.
4. **Find by name and link to it.**
   - List entry names under each group in the sidebar.
   - Give each section an `id`, so a link like `#switch` works.
   - Make slugs match titles: `feedback` becomes `progress`, `surfaces` becomes `plates`.
   - Add search.
5. **Checks that prove what pages claim.**
   - Register entries by import, not by regex: `name: "Mira"` in mock data counts today.
   - Require every exported part to appear in a rendered demo. Today `Field` covers `FieldSet` and others without showing them, and `Separator` is listed but never shown.
